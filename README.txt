SURANE G - PORTFOLIO
====================
1. ADD YOUR PHOTO
   Save your photo as:  assets/photo.jpg   (portrait, about 800 x 1000 px, face near the top)
   Until then, the page shows an "SG" monogram in the same frame.

2. PREVIEW
   Double-click index.html, or run:  python -m http.server 8000  and open http://localhost:8000

3. OPTIONAL
   - Real project links: edit the "View on GitHub" hrefs in index.html.
   - Contact form without an email app: create a free form at formspree.io and paste the URL into FORM_ENDPOINT in js/main.js.
   - Remove the green "Available for internships" line in index.html if it no longer applies.

4. PUBLISH FREE
   GitHub Pages, Netlify (drag the folder) or Vercel. No build step needed.
